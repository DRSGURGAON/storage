# Sections 34–36 — Visual Design Direction, Responsive Design, Mobile Capture

## 34. UI Design Direction

Target: **modern B2B SaaS + logistics professional.** Visual
characteristics: clean, premium, spacious but not wasteful, excellent
typography, consistent spacing, subtle borders, clear status indicators,
professional tables, strong search, fast actions, responsive design.

Avoid: excessive gradients, childish icons, oversized cards, excessive
animation, unnecessary shadows, clutter, a generic template-dashboard
appearance. The application should look trustworthy enough for a warehouse
owner to use for daily business operations.

## 35. Responsive Design

**Desktop** prioritizes: management, billing, reports, masters,
configuration.

**Tablet/mobile** prioritizes: gate entry, GRN, stock lookup, picking,
loading, gate pass, POD, scanning, photos, signature.

Do not simply shrink the desktop UI onto mobile — build proper responsive
workflows suited to each surface.

## 36. Mobile Document Capture

Support camera capture, document upload, damage photos, POD photos, and
signature capture. Attachments must remain associated with the correct
transaction — never a loose, unlinked upload.
